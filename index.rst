Overview
########

CoreSense (*A Hybrid Cognitive Architecture for Deep Understanding*) is a Horizon Europe research project (2022–2026) that develops a theory of understanding and awareness for robots, and a cognitive architecture that implements it on top of ROS 2.

This site is the technical documentation of the CoreSense software. It explains how to install the released packages, the design of the architecture, and how to use the cognitive modules, the engineering toolchain and the ROS 2 instrumentation developed in the project. The project website, with news, publications and public deliverables, is at https://coresense.eu.

All the software is open source and available in the `CoreSense GitHub organisation <https://github.com/CoreSenseEU>`_.
